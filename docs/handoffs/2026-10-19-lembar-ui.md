# Handoff: revamp UI sample toko buku Lembar

Tanggal: 19 Oktober 2026, Asia/Tokyo
Status: selesai secara lokal
Branch dan commit dasar: `main`, `65e49c7`

## Tujuan pemilik

Merombak UI sample toko buku agar jauh lebih modern, clean, dan smooth.
Scope adalah demo Lembar dan representasinya pada portfolio Skyland.

## Kondisi working tree

Working tree bersih sebelum sesi. Semua perubahan saat ini berasal dari tugas
ini; belum dibuat commit atau deployment.

## Yang selesai

- `public/samples/lembar/index.html`: template dan state baru, hero, kategori,
  rak buku, koleksi, bestseller, kurator, social cards, newsletter, footer,
  pencarian, detail buku, keranjang, dan konfirmasi simulasi.
- `public/samples/lembar/lembar.css`: tema putih hangat/sage/lilac, DM Sans dan
  Newsreader, layout responsif, hover/transisi, reduced motion.
- `public/samples/lembar/book-cover.js`: sampul SVG dengan ilustrasi sesuai judul,
  tanpa aset foto eksternal baru; teks di-escape dan warna divalidasi hex.
- Filter katalog dan wishlist aktif; query kosong menampilkan buku. Navigasi
  menuju section atau hasil yang relevan. Format hardcover dan harga ikut
  sampai checkout; format berbeda menjadi item keranjang terpisah.
- Modal dengan focus trap, Escape, pengembalian fokus, inert background,
  dan scroll lock. Checkout/newsletter menjelaskan sifat simulasinya.
- `src/assets/work/lembar.png` diperbarui; palet di
  `src/components/concept/visuals.ts` dan tagline `src/i18n/{en,id,ja}.ts` selaras.
- `scripts/check-lembar.mjs`, DEVELOPMENT.md, dan PROJECT_STATUS.md diperbarui.

## Bukti dan keputusan

Runtime React CDN melalui support.js dipertahankan; tidak mengubah aplikasi
Astro/Preact, harga jasa Skyland, atau API. Data buku dan harga sample tetap
fiktif. Demo berbahasa ID; parameter lang hanya mengubah banner Skyland.
Tidak menambah dependency. Sampul tetap kode SVG dan dipakai di seluruh view.

## Cara melanjutkan

`npm run dev`, buka `/samples/lembar/?lang=id`. Jalankan script pemeriksaan
terhadap server itu memakai `BASE_URL`. Sesi ini juga menggunakan server statis
Python port 4322 untuk folder public, tanpa membaca environment aplikasi.
Artifact pemeriksaan ada di `.shots/lembar/` (tidak di-commit); thumbnail yang
menjadi source portfolio ada di `src/assets/work/lembar.png`.

## Risiko dan pekerjaan di luar scope

Belum diuji di perangkat fisik atau Safari. Wishlist/keranjang tidak persisten;
checkout dan newsletter tetap simulasi browser. Demo membutuhkan React CDN dan
Google Fonts seperti sebelumnya. Tidak mengklaim audit aksesibilitas lengkap.
